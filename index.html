Privacy Policy — Muse Pinterest Integration

Last updated: 13 November 2026

This is a personal-use integration that lets the owner's AI assistant (Muse) read the owner's own Pinterest boards and pins through the Pinterest API. It is not a public service and has no other users.

What data is accessed

With the owner's authorization, the integration reads only:

  • Basic profile information (username, profile details)
  • The owner's boards (names, descriptions)
  • The owner's pins (titles, descriptions, images, links)

It uses read-only permissions. It does not create, edit, or delete boards or pins, and it does not access direct messages, followers, or other users' private data.

How data is used

Data retrieved through the API is used solely to answer the owner's own questions about their Pinterest content — for example, finding a saved pin or reviewing a board. It is not used for advertising, analytics, or any other purpose.

What is stored

OAuth access and refresh tokens are stored securely and used only to maintain the authorized connection. Pin and board content is not copied into any separate database. No data is sold, shared, or disclosed to any third party.

Data retention and deletion

The owner can revoke the integration's access at any time from their Pinterest account settings (Settings → Security → Apps). Revoking access immediately stops all API calls, and any stored tokens are deleted.
